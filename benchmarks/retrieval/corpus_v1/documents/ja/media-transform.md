# 配信用メディア変換の取扱表

| Scope | Rule | Condition |
| --- | --- | --- |
| 透過画像 | 背景を白く塗りつぶさず透過を保持する。出力形式が透過を扱えない場合は要求時に指定された背景色を使い、未指定なら変換を拒否する。 | 商品切抜きの縁が意図せず白くなる事故を避ける。 |
| 向き情報 | 画素を向き情報に従って回転してから向き情報を除去する。情報だけを消す順序は禁止し、出力の見た目を正位置で固定する。 | 向き情報を読まない配信先でも画像を正しく見せる。 |
| 色空間 | 配信用派生画像は指定の標準色空間へ変換し、元の色記述をそのままコピーしない。変換に失敗したものは色不明の成功画像として出さず隔離する。 | 画素と色記述の矛盾を防止する。 |
| アニメーション | 静止画の要求では先頭の表示済み合成フレームを使う。最初の差分画像をそのまま切り出さず、背景との合成結果を保存する。 | 差分フレームだけが表示されて絵が欠ける問題を防ぐ。 |
| 音声波形 | 波形の時間軸は変換後ではなく元音声の時刻に対応させる。無音区間を省略した場合も元の時刻との対応表を別に保持する。 | 波形から選んだ引用を元音声の正しい位置へ戻せるようにする。 |
| 字幕焼込み | 指定言語の字幕が無ければ他言語を自動採用せず欠落を返す。字幕なし配信への切替は別の明示要求でのみ許可する。 | 利用者が読めない字幕で処理を完了扱いにしない。 |
| 個人位置情報 | 公開用派生物から撮影位置と機器識別子を削除する。内部の原本は制限された保管先へ分離し、削除済み派生物のメタデータを原本から再注入しない。 | 公開配信から撮影者や機器を推測されることを防ぐ。 |
| 切抜き指定 | 指定領域が画面外にはみ出す場合は端へ丸めず要求エラーを返す。座標系と原画像の寸法を応答に示し、利用者が指定を修正できるようにする。 | 意図と異なる領域を正常な変換として配信しない。 |
| 派生物の再利用 | 原本の改訂と変換設定の版が一致する場合だけ既存の派生物を再利用する。ファイル名や幅高さの一致だけでは再利用を許可しない。 | 設定改訂前の古い出力が使われ続けることを防ぐ。 |
| 失敗時の公開 | 新しい変換が失敗しても最後の確認済み派生物を削除しない。成功した新世代の公開時にだけ配信参照を切り替え、失敗は別の状態として利用者へ知らせる。 | 一時的な変換失敗で公開済み画像が消えることを防ぐ。 |
