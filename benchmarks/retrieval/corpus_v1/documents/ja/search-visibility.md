# 検索結果の表示許可判定表

| Scope | Rule | Condition |
| --- | --- | --- |
| 検索前の範囲 | 候補を探す時点で要求者の許可範囲を適用する。全契約の候補を取得して画面だけで隠す方式を避け、候補数や順位から他契約の存在を推測できないようにする。 | 検索段階にも契約境界を適用する。 |
| 権限の再確認 | 取得済み候補も応答を組み立てる直前に権限を再確認する。検索中に権限が取り消された資料は省き、古い検索結果の参照で本文を公開しない。 | 検索開始後の権限変更を反映する。 |
| 断片の表示 | 本文を開く権限がない資料は断片だけでも返さない。見出しや強調語にも機密内容が含まれるため、本文を隠して断片を表示する抜け道を作らない。 | 短い検索断片からの内容漏えいを防ぐ。 |
| 結果キャッシュ | 結果の再利用には権限集合の改訂と索引世代を照合する。同じ利用者名と検索語だけでは再利用せず、権限変更や索引更新の後は古い結果を無効にする。 | 利用者名が同じでも表示可能範囲は変化する。 |
| 関連件数 | 非表示にした資料の件数を応答へ含めない。結果が少ない理由として秘密資料の存在を示さず、表示許可された結果だけから件数を計算する。 | 件数表示による機密資料の存在の露出を防ぐ。 |
| 共有リンク | 共有リンクの閲覧者にはリンクで指定した資料の範囲だけを認める。リンク所有者の契約内検索権限を引き継がせず、関連資料の候補へアクセスできると解釈しない。 | 一つの資料の共有から検索範囲が拡張されないようにする。 |
| 削除後の候補 | 索引に残った削除済み資料は元資料の状態検査で除外する。索引の掃除が完了するまで削除前の内容を見せず、除外した候補の補充も許可範囲の中で行う。 | 索引更新の遅れを表示許可の根拠にしない。 |
| 説明文の生成 | 生成する検索説明には表示許可済みの本文だけを渡す。隠した候補を説明の材料に残すと直接の引用がなくても内容を推測できるため、生成処理の入力段階でも範囲を絞る。 | 生成文を通じた権限外情報の混入を防ぐ。 |
| 監査の分離 | 権限不足による除外の詳細は監査領域へ記録する。一般利用者向けの応答には候補の識別子や秘密の分類名を含めず、監査者だけが原因を調査できるようにする。 | 調査可能性と秘密候補の非公開を両立する。 |
| 所有者の変更 | 資料の所有契約が移った場合は旧契約の許可で新しい本文を見せない。索引の識別子が同じでも所有情報を取り直し、旧契約の候補を失効させてから移管先で検索できるようにする。 | 資料移管で古い許可が持ち越されることを防ぐ。 |
