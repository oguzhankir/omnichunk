# Satın alma onay tablosu

| Scope | Rule | Condition |
| --- | --- | --- |
| Donanım talebi | Ekip yöneticisi bütçeyi doğrular | Talebi açan kişi kendi talebinin son onayını veremez. |
| Yazılım aboneliği | Güvenlik incelemesi sözleşmeden önce tamamlanır | Ücretsiz deneme, veri aktarımı kontrolünü ortadan kaldırmaz. |
| Acil bakım | Geçici onay bakım kesintisini gidermek için verilir | Sonradan mali kontrol ve gerekçe kaydı zorunlu kalır. |
| Danışmanlık | Teslim ölçütleri siparişe eklenir | Yalnızca çalışma saati bildirimi teslim kabulü yerine geçmez. |
| Seyahat | Proje kodu harcamanın amacını gösterir | Başka ekibin bütçesi yazılı onay olmadan kullanılamaz. |
| Yenileme | Otomatik yenileme tarihi önceden incelenir | Eski sözleşmenin onayı yeni fiyatı kabul etmek anlamına gelmez. |
| İade | Kabul edilmeyen ürünün satıcıya dönüşü kaydedilir | Fiziksel iade tek başına fatura düzeltmesini kapatmaz. |
| Bölünmüş talep | Bağlantılı siparişler birlikte değerlendirilir | Onay sınırını aşmamak için talebi bölmek kabul edilmez. |
| Yetki devri | Süreli vekil yalnızca belirtilen kapsamda karar verir | Vekalet süresi bitince bekleyen onaylar asıl sorumluya döner. |
| Kapanış | Teslim ve ödeme eşleştirmesi tamamlanır | Çözümlenmemiş uyuşmazlık varsa sipariş kapandı sayılmaz. |
