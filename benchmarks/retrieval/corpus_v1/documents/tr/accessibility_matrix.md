# Erişilebilirlik kabul ölçütleri

| Scope | Rule | Condition |
| --- | --- | --- |
| Klavye odağı | Açılan iletişim kutusu odağı içine alır | Kapatılınca odak kutuyu açan denetime geri döner. |
| Hata mesajı | Hatalı alan metinle tanımlanır | Renk değişimi tek başına doğrulama hatası bildirimi olamaz. |
| Hareket tercihi | Azaltılmış hareket isteği geçişlere uygulanır | Kullanıcının temel görevi tamamlaması animasyona bağlı bırakılamaz. |
| Ekran okuyucu | Asenkron sonuç durumu uygun canlı bölgeyle duyurulur | Her tuş vuruşunda tüm sonuç listesi tekrar okutulmaz. |
| Yakınlaştırma | Dar görünümde içerik akışı korunur | Kritik eylem düğmesi yatay kaydırma dışında kaybolamaz. |
| Oturum süresi | Süre dolmadan uzatma seçeneği sunulur | Güvenlik kuralı gerektirmedikçe kaydedilmemiş içerik uyarısız silinmez. |
| Görsel açıklama | İşlevsel simgenin erişilebilir adı görevini anlatır | Dosya adı anlamlı alternatif metin yerine kullanılamaz. |
| Tablo başlığı | Veri hücreleri ilgili başlıklarla ilişkilendirilir | Görsel hizalama başlık ilişkisini yardımcı teknolojiye iletmez. |
| Dokunma hedefi | Yakın eylemler yanlış seçimi azaltacak şekilde ayrılır | Küçük simge daha geniş etkileşim alanına sahip olabilir. |
| Dil değişimi | İçerikteki farklı dil bölümü açıkça işaretlenir | Sayfanın genel dili başka dildeki alıntının telaffuzunu belirlemez. |
